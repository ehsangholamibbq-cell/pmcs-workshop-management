# UX2-MS67 — Feedback فعال پروفایل در VX-G4

مصرف‌کنندهٔ فعال `/profile` پیام دریافت، ذخیره، موفقیت و خطا را با
Tone و معنای دسترس‌پذیری جدا نشان می‌دهد: Status غیراخطار، Success
غیرادعایی پس از پاسخ معتبر، و Error با `role=alert`. Form هنگام عملیات
واقعاً `aria-busy` می‌شود. متن پیام‌ها و منطق ثبت، مجوز، اسکن تصویر و
Revision تغییر نمی‌کنند. Border و Surface از Tokenهای معنایی موجود
استفاده می‌کنند و رنگ تنها نشانهٔ وضعیت نیست.
انتخاب تصویر تا دریافت دادهٔ پروفایل هم به‌درستی غیرفعال است؛ در
حالت Loading عمل بی‌اثر را فعال جلوه نمی‌دهد.
فیلدهای ویرایشی نیز تا بارگیری پروفایل و هنگام ذخیره غیرفعال‌اند تا
ورودیِ واردشده پیش از دریافت داده یا در میانهٔ ذخیره بی‌صدا جایگزین نشود.

Browser E2E دریافتِ معلق، خطای انتخاب فایل بیش از پنج مگابایت، ذخیرهٔ
معلق و پاسخ موفقِ ایزوله را در ۳۹۰/۳۲۰px می‌سنجد. پاسخ موفق PUT در
مرورگر شبیه‌سازی می‌شود تا دادهٔ QA واقعاً تغییر نکند؛ خود API و Ruleها
همان قرارداد قبلی را دارند. تصاویر و Index شامل Source/Hash/ابعاد پس
از CI باید دریافت و بازبینی شوند. این یک مصرف‌کنندهٔ فعال Feedback است؛
دیگر فرم‌ها/Stateها و Qualification سراسری G4/G5 باز می‌مانند.
