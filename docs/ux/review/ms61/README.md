# UX2-MS61 — بستهٔ تصمیم به‌روز VX-G3

`index.html` چهار معیار مالک را کنار لینک شواهد MS53–MS60 و مرز
G3/G4/G5 می‌گذارد. تصمیم محدود پیشین دربارهٔ جهت کلی، متن فارسی و
تراکم موبایل ثبت است، اما تأیید جداگانهٔ چهار معیار یا پذیرش Gate
نیست. برای هر معیار «تأیید»، «اصلاح با مثال دقیق» یا «شاهد بیشتر» و
در دو حالت آخر مورد و اولویت لازم است.

این صفحه دادهٔ زنده ندارد و هیچ تصمیمی را به‌جای مالک ثبت نمی‌کند.
تصویرهای Browser با Source، Hash صفحه، بایت، SHA-256 و ابعاد واقعی
در سه عرض نماینده منتشر می‌شوند. متن و لینک‌ها، فونت، برند، نبود
overflow و نبود درخواست شبکه‌ای در E2E سنجیده می‌شوند.
