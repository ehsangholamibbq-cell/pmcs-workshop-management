# VX-G5 — Independent qualification contract

- نسخه: `1.2.0`؛ وضعیت: `VX-G5 Visual Qualified` در `PMCS-V1.1-UX2-MS100-C1`؛ Source Run 640 (`36772469486`) و docs Run 642 (`36775276181`) هر دو هشت Job سبز، Artifact `11124980874` معتبر/مرور شده. معیارهای زیر پیش از اجرا Candidate بودند و تغییر داده نشدند.
- پیش‌نیاز: پایان G4 با Full CI Source، Artifact معتبر و CI مستقل مستندات. این فایل بدون Checkpoint و CI مستقل مستندات به‌تنهایی پایان G5 را اعلام نمی‌کند.

## ماتریس مستقل

Chromium، Firefox و WebKit از طریق OIDC واقعی و Fixture ایزوله اجرا می‌شوند. ۱۰ مسیر احراز هویت‌شده و Login مهمان در عرض‌های ۳۲۰، ۳۹۰، ۷۶۸ و ۱۴۴۰ بررسی می‌شوند. بخش‌های امروز، پیشرفت، دفتر فنی، اقدامات، مالی، قرارداد، تدارکات، کیفیت/ایمنی، حاکمیت، تحلیل مشورتی و تنظیمات پروژه در ۳۲۰ و ۱۴۴۰ قاب مستقل دارند؛ سرریز هر بخش در هر چهار عرض سنجیده می‌شود.

در هر مسیر، زبان و RTL سند، بارگذاری وزیرمتن، focus واقعی با Tab، باز/بسته‌کردن Navigation با Enter، reduced-motion و WCAG 2 A/AA و 2.1 A/AA با axe-core بررسی می‌شود. JSON کامل شامل `incomplete` باقی می‌ماند تا موارد نیازمند قضاوت انسان حذف یا به‌اشتباه Pass محسوب نشوند. قاب‌ها مستقل بصری مرور می‌شوند.

Chat فعال با ۶۰ پیام بلند، شش فرم تبدیل، واکنش/پیوست/تبار، انتخاب فایل نامعتبر و حالت‌های آفلاین، دریافت، خطا و لغو مجوز در هر Engine جدا بررسی می‌شود. تاریخچهٔ Reporting با ۵۰ Run و حالت‌های دریافت/خطا/لغو مجوز مستقل است. روند عملیاتی پروژه هر شش وضعیت، تاریخ و پوشش را در متن و فهرست معنایی نمایش می‌دهد؛ رنگ فقط نشانهٔ مکمل است. آزمون خروج از Chat در میانهٔ محاسبهٔ هش، نبود ثبت دیرهنگام فایل محلی را در سه Engine کنترل می‌کند.

Login خطای هویت، نبود نشان رسمی، انتشار واقعی طرح با Asset، خرابی دارایی سفارشی و بازگشت واقعی به نسخهٔ قبلی را می‌سنجد؛ تنظیمات احراز هویت از طراحی مستقل‌اند و آزمایش همیشه طرح اصلی Fixture را بازمی‌گرداند. خرابی نشان سفارشی از نشان رسمی استفاده می‌کند؛ اگر آن هم در دسترس نباشد نام سازمان باقی می‌ماند. خرابی Hero به ترکیب داخلی بازمی‌گردد.

## چاپ و عملکرد

رسانهٔ Print در هر سه Engine آزمون می‌شود. Chromium از پنج حالت نبود Snapshot، جاری، قدیمی، ذخیره‌شده و رد دسترسی، روی A4/A3 عمودی/افقی ۲۰ PDF و پنج قاب می‌سازد. Source، بایت، SHA-256، تعداد/اندازهٔ صفحه، متن قابل استخراج، Font و رندر همهٔ صفحه‌ها باید مستقل بررسی شوند. در رد دسترسی، هیچ برگه یا فرادادهٔ پروژه چاپ نمی‌شود؛ PDF خالی همان رفتار امن قراردادی است.

بودجه‌های ازپیش‌ثبت‌شده در `tools/qa/vx-g5-budgets.json`: مجموع JavaScript فشرده حداکثر ۵۱۲۰۰۰ بایت، CSS حداکثر ۳۲۷۶۸ و Font حداکثر ۲۶۲۱۴۴؛ آماده‌شدن مسیر حداکثر ۱۰ ثانیه، بازشدن Navigation حداکثر ۲۵۰ میلی‌ثانیه، سرریز سراسری حداکثر یک پیکسل، مدت Motion در reduced-motion حداکثر یک میلی‌ثانیه و انیمیشن دائمی صفر. اندازهٔ Build و اندازه‌گیری مرورگر در Artifact نسخه‌دار ثبت می‌شوند. این‌ها سنجهٔ Fixture و Build هستند و SLA تولیدی یا Core Web Vitals کاربران محسوب نمی‌شوند.

## مرز پذیرش

پذیرش فقط با هشت Job سبز Source، کنترل تمام Index/Hash/ابعاد، بررسی بصری قاب‌ها، رسیدگی به نتایج Accessibility و بازبینی PDFهای مرورگر و Goldenهای رسمی و سپس CI مستقل Checkpoint مستندات انجام می‌شود. PDF مرورگر خروجی رسمی Reporting نیست؛ Goldens رسمی PDF/XLSX و Font در همان CI Backend مستقل‌اند. مجوز PDF همچنان Unconfigured و Feature Flagهای عملیاتی خاموش‌اند. این آزمون Engineهای Linux را پوشش می‌دهد؛ اجرای بومی iOS/Safari یا Edge روی Windows و آزمون کاربر واقعی در محیط شرکت در QA1 بعدی قرار دارد. INT1/QA1 و قفل V1.1 با پایان UX2 بسته نمی‌شوند.

بازبینی Artifact Run 638 با وجود PDFهای درست، قاب `current` چاپ را به‌دلیل ثبت زودهنگام رد کرد.
