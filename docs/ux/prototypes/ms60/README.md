# UX2-MS60 — نمونهٔ فرم شمسی و فیلتر

این صفحهٔ مستقل ده State مرتبط را برای ورودی تاریخ شمسی، Select فیلتر،
پیام خطا/موفقیت و جدول نمایشی می‌سنجد. تاریخ‌ها و ردیف‌ها ساختگی‌اند؛
هیچ درخواست، تبدیل تاریخ به مقدار رسمی، خواندن یا نوشتن پروژه انجام نمی‌شود.

در حالت تاریخ نامعتبر و بازهٔ ناسازگار، خطا به ورودی مربوط است و نتیجهٔ
پیشین پنهان می‌شود. Loading جای‌نگهدار خنثی دارد. خطا، آفلاین، منع مجوز،
بدون نتیجه و نتیجهٔ کهنه با متن مستقل از رنگ مشخص‌اند. Apply فقط وضعیت
نمونه را تغییر می‌دهد. این شاهد `P` در ماتریس Foundation است؛ رفتار
تقویم، parser واقعی، درخواست فیلتر و مصرف‌کنندگان فعال در `VX-G4/G5`
جداگانه سنجیده می‌شوند.

Browser E2E روی عرض‌های ۱۲۸۰، ۳۹۰ و ۳۲۰، Label/Help/Error، قفل Action،
پنهان‌سازی ردیف، Focus، فونت، overflow و نبود درخواست شبکه‌ای را می‌سنجد.
Artifact از همان Run با Source، Hash Prototype، SHA-256، بایت و ابعاد
واقعی هر تصویر ساخته می‌شود.
