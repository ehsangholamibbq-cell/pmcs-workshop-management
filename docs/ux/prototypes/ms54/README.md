# UX2-MS54 — اصلاح محدود متن و تراکم موبایل

این نمونه نسخهٔ مستقل ترکیب MS52 است؛ فایل‌ها، Screenshotها و Hashهای
MS52 دست‌نخورده می‌مانند. تأیید مالک برای جهت بصری در
`docs/ux/review/ms54-owner-decision.md` با دو پیگیری ثبت شد: متن
قابل‌نمایش فارسی و تراکم کمتر موبایل.

در این نسخه واژه‌های فنی انگلیسیِ متن نمونه با توضیح فارسی جایگزین
شده‌اند. عرض ۳۲۰ و ۳۹۰ پیکسل با Padding و ارتفاع کمتر Login/Shell
نمایش داده می‌شوند؛ کنترل‌ها حداقل ۴۴px و نمودار و جدول جایگزین
همچنان حاضرند. Stateهای بدون داده، بارگذاری، خطا، بدون مجوز و آفلاین
همان مرز حقیقت را حفظ می‌کنند. ورود و درخواست عملیاتی وجود ندارد.

E2E ارتفاع کل صفحه را نسبت به MS52 در همان عرض و فونت مقایسه می‌کند،
هر شش State، Navigation/Focus، نبود overflow و متن قابل‌نمایش را
می‌سنجد و تصویرها را با SHA-256 و Source در Artifact جدا ثبت می‌کند.
این شواهد فقط اصلاح Prototype را ثابت می‌کنند؛ `VX-G3`، مهاجرت
`VX-G4` و Qualification `VX-G5` هنوز جدا هستند.
