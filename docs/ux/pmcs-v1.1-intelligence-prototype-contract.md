# PMCS V1.1 — قرارداد نمونهٔ بصری هوشمندی مدیریتی

- شناسه: `PMCS-UX-INTELLIGENCE-PROTOTYPE-001`
- نسخهٔ Candidate: `0.1.0` در UX2-MS59
- مرجع: `PMCS-DS-001`، `PMCS-RM-VISUAL-001` و برنامهٔ هفت‌مرحله‌ای Agent.
- مرز نسخه: این فقط Prototype `VX-G3` است؛ UI اجرایی Agent و Stageهای
  ۲ تا ۷ در V1.2 قرار دارند. `INT1` در V1.1 صرفاً Foundation مستقل است.

## حقیقت و منشأ

میز تحلیل، پرسش/نتیجه را به Bubble پیام گروه پروژه تبدیل نمی‌کند.
هر پیشنهاد با برچسب فرضیه، منشأ، زمان/تازگی، عدم قطعیت و دامنهٔ مجوز
نمایش داده می‌شود؛ Fact رسمی، پیش‌نویس و اقدام انسانی برچسب مستقل دارند.
منبع ناموجود، بی‌مجوز، آفلاین، کهنه، متعارض یا دارای خطا نباید به
پیشنهاد معتبر و قابل اقدام ارتقا یابد. نسخه و مجوز واقعی در هر خواندن
و در لحظهٔ تصمیم دوباره ارزیابی می‌شوند.

## وضعیت‌های نمونه

| وضعیت | نمایش | مرز اقدام |
| --- | --- | --- |
| بدون تحلیل، Loading | پیام یا جای‌نگهدار خنثی، بدون نتیجه | همهٔ Actionها قفل |
| پیشنهاد آزمایشی | فرضیه، منشأ فرضی، عدم قطعیت و گام انسانی | فقط مرور محلی منشأ؛ Draft و اقدام قفل |
| عدم قطعیت بالا | هشدار صریح کنار همان فرضیه | فقط مرور محلی؛ هیچ توصیهٔ قطعی |
| منبع کهنه | هشدار نسخه/تازگی و پیشنهاد قدیمیِ برچسب‌دار | مرور و اقدام قفل تا بازخوانی |
| منع مجوز، آفلاین، خطا، تعارض نسخه | فرضیه و منبع حفاظت‌شده پنهان | همهٔ Actionها قفل |

نمونهٔ MS59 هیچ Model Gateway، Tool، API، Chat entry point، ذخیرهٔ
پیش‌نویس یا عملیات رسمی ندارد. هیچ شناسهٔ منبع/Hash واقعی در آن ادعا
نمی‌شود. `@PMCS` فقط پس از Gateهای Stageهای ۲، ۳ و ۴ آینده می‌تواند
ورودی کنترل‌شدهٔ Room گروه پروژه باشد؛ رابط اصلی مرکز هوشمندی است.

## Evidence و Gate

Browser E2E باید برچسب State، پنهان‌سازی Permission، قفل Action،
Focus/Escape مرور محلی، نبود درخواست شبکه‌ای و ۳۲۰/۳۹۰/۱۲۸۰px را
بیازماید. Artifact تصویری با Source، Hash Prototype، بایت، SHA-256
و ابعاد واقعی بازبینی شد. Run 453 با هشت Job موفق و Artifact
`11023743292` با ۱۵ PNG معتبر Evidence نمونه‌اند. `VX-G3` علاوه بر
این نمونه به قرارداد Foundation و تصمیم صریح
مالک نیاز دارد؛ `VX-G4/G5` مهاجرت و Qualification محدودهٔ V1.1 را
جداگانه می‌سنجند، نه UI اجرایی آیندهٔ Agent را.
