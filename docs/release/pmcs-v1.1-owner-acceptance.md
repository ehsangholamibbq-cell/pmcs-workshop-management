# PMCS V1.1 — چک‌لیست پذیرش کامل مالک محصول پیش از انتشار

- شناسه Gate: `PMCS-V1.1-OWNER-ACCEPTANCE-001`
- وضعیت: `Planned — اجرا نشده`
- تصمیم حاکم: [ADR 0034](../adr/0034-v1.1-owner-acceptance-and-release-gate.md)
- Candidate/Commit SHA: `ثبت می‌شود پس از قفل Baseline`
- Artifact/Hash: `ثبت می‌شود پس از آماده‌شدن Candidate`
- محیط و زمان آزمون: `ثبت توسط مالک هنگام اجرا`
- تصمیم مالک: `در انتظار آزمون`

این آزمون پس از QA1 و قفل Baseline انجام می‌شود و پیش از انتشار رسمی است. هر مورد باید
با نتیجهٔ `Pass`، `Fail` یا `N/A` و شاهد/یادداشت ثبت شود. `N/A` باید دلیل داشته باشد؛
مورد Fail مسدودکننده انتشار است تا رفع و آزمون Candidate جدید ثبت شود. این فرم جایگزین QA1
نیست و هیچ اتصال زندهٔ Provider را برای V1.1 مطالبه نمی‌کند؛ INT1 باید در انتشار خاموش باشد.
