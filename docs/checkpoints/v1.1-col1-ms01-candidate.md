## Connected evidence

Identity membership contract, permission matrix, default project room,
monotonic per-room sequence and stable client message ID are implemented.

duplicate retries with the same content return the original identity, while
changed content conflicts. Audit, outbox and idempotency receipt commit with

permission separation, descriptor and default-off rollout. Connected QA

offline-key retry, changed retry denial, cross-project denial and suspension

sequence/client IDs and three corresponding Audit/Outbox records. Full CI
includes V1 regression, PostgreSQL migration/restore, Web and real browser.
