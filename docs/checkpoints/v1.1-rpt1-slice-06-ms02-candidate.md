## مرز این Micro-Step

این Checkpoint همان MS02 بازمانده از Checkpoint قبلی را می‌بندد و هیچ API خارجی، Migration،
معماری، Scope یا ترتیب Roadmap را تغییر نمی‌دهد. Qualification متصل زیر روی PostgreSQL و MinIO
ایزوله اجرا شد:

1. ایجاد ۲۰ Run سالم XLSX و یک poison Run با identity قطعی؛
2. اجرای Worker با `MaximumAttempts=3` و failure injection محدود به QA Gateway؛
3. اثبات دو requeue و یک failure نهایی poison، بدون Output/Document/completion event؛
4. اثبات تکمیل یک‌بارهٔ هر ۲۰ Run سالم با یک Output و یک Generated Document؛
5. اندازه‌گیری P95 از زمان Queue تا Completion در dataset مرجع؛
6. اجرای fairness واقعی برای سه Run پروژه A و یک Run پروژه B با دو Worker و دو row lock مستقل؛
7. اثبات انتخاب پروژه B پیش از Run دوم و سوم پروژه A و rollback پاک پس از `SIGKILL`؛
8. کنترل Audit، Outbox، Idempotency، health و پاک‌سازی کامل fixtureهای موقت.
