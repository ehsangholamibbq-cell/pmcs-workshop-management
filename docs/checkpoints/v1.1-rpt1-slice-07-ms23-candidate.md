## Runtime Core و مرز Source

TechnicalOffice اکنون `IProjectTechnicalOfficeReportingSource` خواندنی، نسخه‌دار و cutoff-aware دارد.
این Source پنج دفتر را در یک PostgreSQL repeatable-read transaction، با Tenant/Project scope و
سقف `20,000/100,000/50,000/50,000/50,000` ردیف Document/Revision/Transmittal/RFI/Submittal
می‌خواند؛ `Take(max+1)` overflow را failure می‌کند. deadline خواندن `30s` است.
`GET /technical-office/state`، HTTP DTO، دادهٔ مالی/تأمین و Persistence ماژول دیگر استفاده نمی‌شوند.

Selector مالک TechnicalOffice هویت، شماره/Revision یکتا، linkهای هم‌پروژه، ترتیب و gap event،
عمق lineage `100` و سقف event `500,000` را validate می‌کند. Official Document تنها از
Approved Revision و Transmittal Issue متقابل تا cutoff ساخته می‌شود؛ Acknowledge مستقل و
بعد از cutoff به گذشته منتقل نمی‌شود. supersession فقط با زنجیره و timestamp سازگار پذیرفته
می‌شود. RFI issue/response/accept/close و Submittal review outcome جدا در قرارداد رویدادی
پشتیبانی می‌شوند؛ `ForInformation` از Approval محتوای سند جدا می‌ماند.

مدل فعلی RFI و Submittal زمان تمام transitionهای میانی را ذخیره نمی‌کند. Adapter فعلی برای
هر یک از این دو دفتر که رکورد دارد، coverage را `Incomplete` می‌دهد؛ Calculator آن بخش را
`InsufficientData` با شمارندهٔ null و بدون ردیف رسمی منتشر می‌کند. اگر دفتر واقعاً خالی و
enumeration کامل باشد، `NoData` با صفر اثبات می‌شود. هیچ current-status، latest-row یا حدس
تاریخی جای این خلأ را نمی‌گیرد. Document و Transmittal واجد lineage معتبر می‌توانند مستقل
`Available` بمانند. event producer تاریخی، backfill یا Migration در MS23 اضافه نشده است.

Manifest محافظت‌شده شامل version/policy، cutoff/local date، configuration، classification،
watermark، completeness هر دفتر، count/range/event-count و SHA-256 factهای مرتب است؛ سقف
`8,000,000` byte دارد. semantic hash مستقل از ترتیب query/RunId ساخته می‌شود. Snapshot Builder
Project profile پین‌شده، Time Zone، config version، Tenant/Project، cutoff، manifest و
semantic hash را دوباره validate و فقط دادهٔ allowlist شده را serialize می‌کند. فایل، URI،
hash فایل، متن RFI/Review، recipient و respondent وارد Payload نمی‌شوند. Classification حداقل
