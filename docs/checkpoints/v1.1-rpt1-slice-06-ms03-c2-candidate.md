## مرز این Checkpoint

این Candidate ادامهٔ مستقیم C1 و Safe Checkpoint بسته‌شدن MS03 است؛ Scope، API تجاری، Migration،
ترتیب Roadmap یا مرز Bounded Contextها را تغییر نمی‌دهد. تغییرهای عملیاتی محدودند به:

1. ثبت OpenTelemetry فقط در composition پروژه API و فقط هنگام وجود
   `Observability:OtlpEndpoint`؛ ماژول Reporting هیچ dependency به SDK/exporter ندارد؛
2. default-off بودن exporter و رد fail-closed URI نسبی، scheme غیر HTTP(S)، credential، query یا
   fragment در startup؛
3. subscription فقط به Meterهای پایدار `Pmcs.Api` و `Pmcs.Reporting` و ارسال OTLP/gRPC؛
4. Collector نسخه‌پین‌شده با translation صریح Prometheus، scrape loopback و حذف scope label؛
5. سه rule مستقل برای queue age، heartbeat گمشده/کهنه و failure/retry؛
6. Alertmanager نسخه‌پین‌شده با webhook دارای `send_resolved=true`؛
7. Qualification متصل Collector → Prometheus → Alertmanager → receiver در همان pause قطعی دو
   Worker و صف aged؛
8. کنترل نبود Tenant، Project، User یا Run ID در payload metric و alert.

پیکربندی loopback موجود یک deployment contract و harness ایزولهٔ CI است. TLS، authentication،
network policy، storage retention و receiver واقعی هر محیط همچنان مسئولیت استقرار هستند و هیچ
credential در Repository قرار نگرفته است.
