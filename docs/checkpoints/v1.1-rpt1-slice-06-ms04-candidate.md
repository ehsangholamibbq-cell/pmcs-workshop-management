## مرز این Checkpoint

این Candidate ادامهٔ مستقیم MS03-C2 است و Scope، API تجاری، Migration، ترتیب Roadmap یا مرز
Bounded Contextها را تغییر نمی‌دهد. MS04 فقط یک مسیر عملیاتی داخلی و default-off برای Generated
Documentهای `ReportOutput` اضافه می‌کند:

1. modeهای صریح `Disabled`، `InventoryOnly` و `ApplyEligible`؛
2. grace حداقل ۲۴ ساعت، pagination، batch و سقف bounded هر sweep؛
3. اثبات نبود owner در Reporting و lineage یکتای release Audit به Run؛
4. محدودشدن eligibility به Run نهایی `Failed/Failed` با `output_count=0`؛
5. advisory transaction lock مشترک Run میان Retry و remediation؛
6. recheck هویت، revision، state، retention و legal hold در Documents زیر `FOR UPDATE`؛
7. حذف object و metadata فقط برای retention منقضی و بدون hold؛
8. Audit یکتای `GeneratedReportOrphanRemediated` بدون object key؛
9. idempotency در اجرای دوباره و حفظ Candidateهای owned، protected، recoverable یا ambiguous.

قرارداد Documents فقط metadata لازم برای تصمیم مالک را برمی‌گرداند و object key از مرز ماژول خارج
نمی‌شود. هیچ endpoint حذف عمومی، Permission bypass یا Migration جدید ایجاد نشده است.
