## خروجی Slice 02

1. Contract باریک `IGeneratedDocumentPublisher` در مالک Documents اضافه شد؛ Reporting object key،
   presign یا upload session عمومی دریافت نمی‌کند؛
2. Generated output با stable Document ID، path server-generated، allowlist media/extension، signature،
   size، SHA-256، exact-byte read-after-write، Release سیستمی، `LongTerm` retention، Audit و
   `documents.asset.released.v1` منتشر می‌شود؛
3. Shared Document reference برای verification فقط metadata لازم Retention/LegalHold را صادر می‌کند
   و generic Documents access برای `ReportOutput` همچنان fail-closed است؛
4. Adapterهای مستقل PDF و XLSX ثبت شدند. PDF دارای A4/Portrait، RTL، فونت فارسی صریح، metadata
   pin‌شده، header/footer/page number و data-status state است. XLSX یک OpenXML deterministic با
   metadata/data sheet، RTL، freeze/filter، numeric cells و formula-injection protection می‌سازد؛
5. stable Output/Document identity، manifest hash، verification code، نام فایل شمسی و تبدیل
   Jalali/Tehran پیاده شد؛
6. Worker از `SnapshotReady` به `Rendering → Succeeded` ادامه می‌یابد، تمام formatها را پیش از هر
   publish رندر/اعتبارسنجی می‌کند، stable retry/crash recovery دارد و final Output/Run/Audit/Outbox
   را transactionally ثبت می‌کند؛
7. Retry محدود و صریح، Cancel پیش از Rendering، Download و Verify permission-aware، current Source
   permission recheck، ETag/no-store/nosniff و integrity-failure Audit اضافه شد؛
8. `OutputAccessEnabled` از Create/Catalog جدا شد تا rollback بتواند تولید جدید را ببندد ولی در نبود
   Incident امنیتی، خروجی‌های موجود را قابل Download/Verify نگه دارد؛
9. Migration شمارهٔ 43 unique verification-code constraint را به index غیر unique تبدیل کرد؛ چون
   دو Manifest معنایی برابر می‌توانند verification code برابر و Output identity جدا داشته باشند؛
10. TestHarness سناریوی Catalog → Create/Replay/Conflict → Worker → XLSX → Documents → Download/
    Verify را به‌همراه Observer/Cross-project denial و PDF license fail-closed + Retry آماده کرد؛
11. QA دیتابیس stateهای Run/Snapshot/Output، Released Document، Retention، Migration 43، Audit،
    Outbox و Idempotency را assert می‌کند؛
12. read-only Reporting application service نیز پشت runtime gates قرار گرفت تا Toolهای Agent آینده
    هنگام خاموش‌بودن feature داده‌ای برنگردانند.

سازمان است و در این Slice فرض نشده است. QA فعلی فقط اثبات می‌کند وضعیت تنظیم‌نشده fail-closed است.
