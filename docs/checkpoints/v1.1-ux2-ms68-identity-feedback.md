## برش اجراشده

در `/admin/users` دریافت فهرست در حالت Loading دادهٔ قبلی را به‌عنوان
وضعیت جاری نشان نمی‌دهد؛ خطای دریافت با `alert` و متن فارسی مشخص است و
فرم عملیاتی تا دریافت مرجع رسمی حاضر نمی‌شود. بازخورد ثبت دعوت در
Loading/Success از Error جداست؛ هنگام ثبت، ورودی‌ها Busy/Disabled
می‌شوند. شکست ثبت، نام/ایمیل/نقش/پروژهٔ انتخابی را پاک نمی‌کند.
برای Retry همان payload، Idempotency Key ثابت می‌ماند و تغییر ورودی
هویت فرمان تازه می‌سازد. تست مرورگر با پاسخ‌های شبیه‌سازی‌شده هیچ دعوتی
در دادهٔ QA ثبت نمی‌کند. Permission و مرز Tenant/Project تغییر نکرده‌اند.

Full Web Check محلی شامل ۱۸۸ تست واحد، Lint، ممیزی فارسی/شمسی و Build
تولیدی، به‌همراه Architecture و Pilot Contract سبز بود. Run 482 با
درخت کد یکسان هشت Job سبز داشت؛ Run 483 فقط assertion متن خطای ۵۰۳
را ناسازگار کرده بود و Run 484 همان assertion معتبر را به‌صورت
fast-forward برگرداند. Artifact نهایی `pmcs-ms68-identity-feedback`،
