## دامنه و نتیجه

`VX-G4` پیش‌تر پس از ممیزی ۱۱ Route و ۴۱ Component فعال بسته شد. این MS آزمون مستقل `VX-G5` را روی Chromium، Firefox و WebKit اجرا می‌کند: ده Route احراز هویت‌شده و Login، چهار عرض ۳۲۰/۳۹۰/۷۶۸/۱۴۴۰، قاب‌های بخش‌های پروژه، وضعیت‌های پرتراکم Chat و Reporting، شش وضعیت روند عملیاتی، بازگشت طرح Login، Focus/RTL/فونت وزیرمتن ۲٫۰٫۰، reduced-motion و WCAG 2/2.1 A/AA. سناریوی خروج از Chat هنگام هش فایل، نبود آپلود محلی دیرهنگام را در هر سه Engine می‌سنجد. Mock APIهای وضعیت پرتراکم با Service Worker مسدودشده از پاسخ واقعی Default خاموش جدا شده‌اند؛ سناریوهای Default خاموش مستقل هستند.

Indexهای Artifact، SHA-256، بایت و ابعاد تصاویر به Source واحد گره خورده‌اند؛ فایل بدون Index وجود ندارد. JSON کامل axe شامل موارد `incomplete` حفظ شده است؛ نقش پنل‌های Chat و برچسب فایل بر اساس یافته‌های قطعی اصلاح شدند. در ۱۹۵ اجرای axe Run 640 هیچ `violation` باقی نماند. تمام موارد `incomplete` از نوع `color-contrast` بودند؛ ۵۸۸۷ Node به‌عنوان Pass خودکار شمرده نشده‌اند. قاب‌های Login، Profile، Chat، Reporting، پروژه و روند در Engineها و عرض‌های مختلف به‌صورت بصری بازبینی شدند؛ قضاوت انسانی جامع‌تر و آزمون با کاربر واقعی در QA1 باقی است. قاب چاپ Run 638 جداگانه رد شد: `current` پیش از تثبیت مشخصات پروژه ثبت شده بود.
