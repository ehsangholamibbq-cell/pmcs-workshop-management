## دامنه و نتیجه

`VX-G4` پیش‌تر پس از ممیزی ۱۱ Route و ۴۱ Component فعال بسته شد. این MS آزمون مستقل `VX-G5` را روی Chromium، Firefox و WebKit اجرا می‌کند: ده Route احراز هویت‌شده و Login، چهار عرض ۳۲۰/۳۹۰/۷۶۸/۱۴۴۰، قاب‌های بخش‌های پروژه، وضعیت‌های پرتراکم Chat و Reporting، شش وضعیت روند عملیاتی، بازگشت طرح Login، Focus/RTL/فونت وزیرمتن ۲٫۰٫۰، reduced-motion و WCAG 2/2.1 A/AA. سناریوی خروج از Chat هنگام هش فایل، نبود آپلود محلی دیرهنگام را در هر سه Engine می‌سنجد. Mock APIهای وضعیت پرتراکم با Service Worker مسدودشده از پاسخ واقعی Default خاموش جدا شده‌اند؛ سناریوهای Default خاموش مستقل هستند.

Indexهای Artifact، SHA-256، بایت و ابعاد تصاویر به Source واحد گره خورده‌اند؛ فایل بدون Index وجود ندارد. JSON کامل axe شامل موارد `incomplete` حفظ شده است؛ نقش پنل‌های Chat و برچسب فایل بر اساس یافته‌های قطعی اصلاح شدند. در ۱۹۵ اجرای axe هیچ `violation` باقی نماند. هر ۱۹۵ فایل یک مورد `incomplete` از نوع `color-contrast` دارد، چون ابزار رنگ پس‌زمینهٔ گرادیانی را تعیین نکرد؛ ۵۸۰۷ Node به‌عنوان Pass خودکار شمرده نشده‌اند. قاب‌های نمونهٔ Login، Profile، Chat، Reporting، پروژه، روند و چاپ در Engineها و عرض‌های مختلف به‌صورت بصری بازبینی شدند؛ قضاوت انسانی جامع‌تر و آزمون با کاربر واقعی در QA1 باقی است.

برای چاپ، ۲۰ PDF Chromium از پنج حالت پروژه در چهار ترکیب A4/A3 عمودی/افقی و قاب Print سه Engine بررسی شد. هر ۲۰ فایل یک‌صفحه‌ای است؛ ۱۶ PDF غیرممنوع متن و قلم وزیرمتن و وضعیت درست دارند، شناسهٔ Snapshot در current/outdated/cached حاضر و در no-snapshot غایب است. چهار PDF لغو دسترسی بدون متن و قلم‌اند و دادهٔ پروژه را افشا نمی‌کنند. آزمون Source متن استخراجی هر PDF را حین CI کنترل می‌کند؛ همهٔ ۲۰ فایل این Artifact در نخستین تلاش ساخته شدند. رندر نمونه‌های A4 جاری، A3 ذخیره‌شده و A4 لغو دسترسی نیز بازبینی شد. Goldenهای رسمی Backend مستقل از چاپ مرورگر هستند.

بودجه‌های JavaScript/CSS/Font فشرده و آماده‌شدن مسیر، Navigation، سرریز، Motion و انیمیشن دائمی با `tools/qa/vx-g5-budgets.json` تطبیق دارند: JavaScript برابر ۴۴۱٬۶۷۲ از ۵۱۲٬۰۰۰، CSS برابر ۱۸٬۷۱۳ از ۳۲٬۷۶۸، Font برابر ۱۱۱٬۱۵۲ از ۲۶۲٬۱۴۴ بایت. در Fixture، بیشینهٔ آماده‌شدن ۱۳۲ مسیر/عرض ۱۰۱۷ از ۱۰٬۰۰۰ میلی‌ثانیه و بیشینهٔ بازشدن ۱۰۲ Navigation برابر ۴ از ۲۵۰ میلی‌ثانیه است. این سنجه‌ها متعلق به Fixture لینوکس‌اند و SLA تولیدی یا آزمون کاربران واقعی نیستند.
