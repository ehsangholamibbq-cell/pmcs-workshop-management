## Connected evidence

Authorized WebSocket events carry message identity, project, sequence and UTC
time without text or bytes. Each connection has a bounded lifetime and checks
active account, membership and read permission during replay and dispatch.
The durable sequence and permission-filtered HTTP long poll are authoritative
for reconnect and gaps; the signed-in BFF can use the fallback. The Web client
queues stable client IDs in an identity-scoped IndexedDB v8 store, preserves
the payload on transport failure and retries with the same idempotency key.

Connected QA exercised two actors receiving the same new event, HTTP fallback,
reconnect replay, duplicate retry and cross-project/cursor negatives. The real
Chromium test persisted a queued message across reload, isolated another user
and retried after a failed transport with identical IDs. Full CI included the
V1 regression, PostgreSQL restore and all eight jobs.
