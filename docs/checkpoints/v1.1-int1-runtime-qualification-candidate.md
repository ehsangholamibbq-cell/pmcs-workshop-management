## مرز پذیرش

آزمون اتصال زندهٔ پیکربندی‌شدهٔ OpenAI، Gemini و Claude باید بدون افشای Credential اجرا و نتیجهٔ هر دو قابلیت structured output و tool calling برای هر مدل ثبت شود. Run 674 و fixture CI، این آزمون را جایگزین نمی‌کنند. فقط پس از تطبیق همهٔ بندهای ADR 0032 و Risk Register می‌توان Checkpoint خروج مستقل و وضعیت Safe را ثبت کرد.

ریسک `R-AI-03` تا شواهد اتصال زنده باز می‌ماند؛ `R-AI-02` و `R-AI-04` با آزمون سقف/مرز و بازرسی DB/log پیگیری شده‌اند، اما پذیرش نهایی آن‌ها به Source و CI یکسان و مرور Gate وابسته است. هیچ کلید یا پاسخ خام Provider در این Candidate نگهداری نمی‌شود.

Stage 2 Agent، QA1 و قفل V1.1 در این Candidate شروع نشده‌اند. Reference Run در پیکربندی پیش‌فرض خاموش می‌ماند.
