## Agent readiness effect

RPT1 باید Application Serviceهای read-only زیر را برای Stage 1 Agent قابل Manifest کند، ولی در این
Checkpoint Agent اجرا نمی‌شود:

- Catalog مجاز؛
- Run status مجاز؛
- Output metadata مجاز.

Tool read-only آینده همان Permission کاربر را دوباره ارزیابی می‌کند و به Reporting DbContext یا
SQL دسترسی مستقیم ندارد.
