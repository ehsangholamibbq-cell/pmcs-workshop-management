# ADR 0010 — Portfolio State without Composite Health

- Status: Accepted
- Date: 2026-09-10

## Context

مدیرعامل به نمای چندپروژه‌ای نیاز دارد، اما داده پروژه‌ها هم‌سطح و هم‌کامل نیست: ممکن است پروژه‌ای WBS نداشته باشد، بودجه اولیه‌اش هنوز تصویب نشده باشد، HSE در آن فعال نباشد یا کاربر به مالی یک پروژه دسترسی نداشته باشد. تبدیل این ناهمگنی به یک نمره یا رنگ کلی، نبود داده را با عملکرد خوب/بد اشتباه می‌گیرد و علت تصمیم را پنهان می‌کند. جمع‌زدن مبالغ با ارزهای متفاوت نیز بدون نرخ و تاریخ تبدیل معتبر نیست.

## Decision

- Portfolio Command Center سه وضعیت Operational، Financial و Commercial را مستقل نمایش می‌دهد و `OverallHealth`، امتیاز وزنی یا رنگ کلی پروژه تولید نمی‌کند.
- پروژه بدون Snapshot عملیاتی صریحاً `NoData` است و هرگز Stable فرض نمی‌شود. Snapshot قدیمی و Snapshot نیازمند محاسبه نیز پرچم جداگانه دارند.
- `NotConfigured`، `NotEnabled`، `SetupRequired`، `NoData` و `Suspended` برای قابلیت‌های اختیاری حفظ می‌شوند؛ WBS، Budget و HSE در مخرج ارزیابی ساختگی وارد نمی‌شوند.
- جمع مالی و تعهدات فقط به تفکیک `currencyCode` ارائه می‌شود. تبدیل ارز و جمع کل چندارزی تا زمان وجود FX policy نسخه‌دار ممنوع است.
- Header فقط شمارش‌های شفاف، Action Exception، Approval Exception و Exposureهای هم‌ارز را ارائه می‌کند.
- قرارداد پاسخ با `portfolio-command-center-v1` نسخه‌دار است. هر وضعیت منبع شناسه/نسخه Snapshot خود را حفظ می‌کند؛ Read Model سبد در V1 به‌صورت on-demand ساخته می‌شود و Snapshot تاریخی مستقل Portfolio ذخیره نمی‌کند.
- دامنه پروژه‌ها از تقاطع `portfolio.read` و `project-state.read` کاربر ساخته می‌شود. مالی، تجاری و اقدامات هر پروژه دوباره با Permission scope همان بعد محدود می‌شوند.
- Portfolio V1 برای Staff یک نمای online-first است؛ Offline-first همچنان الزام Field App و ثبت واقعیت کارگاه است.

## Consequences

- مدیر می‌تواند علت هشدار، کیفیت و تازگی داده و مسئول اقدام را ببیند، بدون آنکه نمره ترکیبی اعتماد کاذب بسازد.
- پروژه‌های دارای پیکربندی متفاوت قابل مقایسه‌اند، اما فقط در ابعاد واقعاً موجود و مجاز.
- مصرف‌کننده هوش مدیریتی آینده باید همین ابعاد و lineage را cite کند و اجازه استنتاج وضعیت کلی رسمی ندارد.
- Trend تاریخی Portfolio و FX consolidation در صورت نیاز آینده به قرارداد و موتور مستقل نیاز خواهند داشت.
